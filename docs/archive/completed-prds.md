# Completed PRDs

Compressed record of shipped PRDs that previously lived in `docs/engineering/` as full documents. All three completed July 2, 2026 (see `docs/devlog.md`). Kept as a one-line-each reference in case the original reasoning is ever needed — full write-ups are in git history if more detail is required.

*   **Howdy Email**: Replaced `hello@outatl.com` with `howdy@outatl.com` across public-facing contact surfaces (e.g. `PartnerForm.tsx` error/fallback text).
*   **Performance**: Hit 100/100 Lighthouse Performance by self-hosting `Outfit`/`PlusJakartaSans` variable fonts in `public/fonts/` (removed external Google Fonts import), lazy-hydrating `InteractiveMap` (`client:load` → `client:visible`), and replacing `transition-all` with `transition-colors` on `FanFestLineupBanner.tsx` to avoid non-composited layout animations.
*   **Accessibility**: Hit 100/100 Lighthouse Accessibility/Best Practices by enforcing 44×44px touch targets on `InteractiveMap.tsx` pins, raising contrast on filter chip text/count badges (`DirectoryFinder.tsx`, `global.css`), and standardizing all "Interactive Map" links to `/map` / `/es/map` in `Navbar.astro`.
*   **FAQ Overhaul** (July 12, 2026): Consolidated the two disconnected FAQ implementations into one system — expanded and categorized the business FAQ (`list-your-business-{en,es}.md`), built a new standalone `/faq` + `/es/faq` product FAQ (sourced from `i18n/{en,es}.ts`'s `productFaq`, not a new heavy `landing_pages` entry as originally proposed — the collection's schema requires too many unrelated fields), removed the hardcoded/non-i18n mini-FAQ from `WorldCupSection.astro`, added a Footer nav link, and upgraded `FAQSection.tsx` with category grouping, `aria-controls` linking, hash deep-linking, content-driven height (replacing a fragile `max-h-96` clip), and Umami `faq_open` event tracking.
